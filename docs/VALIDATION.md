# v0.4 单机验证报告

本版把安装、检索、核实证据、解释漏检、资源控制、数据库配置和维护串成用户闭环。下列记录只说明已经执行的环境；物理 8GB/16GB、真实数百 GB 资料和长期运行验收仍待补齐。v0.3 的完整历史数据保留在 [历史验证报告](VALIDATION-v0.3.md)。

## 功能回归与产品路径

Windows 11（内核 10.0.22631）、Python 3.11.3、i7-13700、24 逻辑核、实际内存 31.814GiB。开发阶段全量回归为 **430 passed、5 skipped，43.39 秒**；跳过一个非 Windows 分支、四个单独配置的数据库测试。发行前结果及 CI 以本页后续记录为准。

组合筛选、文件名精确优先、上下文锚点、诊断与局部刷新、范围撤销、重复折叠、同路径替换和旧引用拒绝，由 [用户路径测试](../tests/test_product_journeys.py) 与 [官方 MCP 集成测试](../tests/test_mcp_integration.py) 验证。MCP 实际发现并调用 11 个工具。

v0.3 文件记录没有文件身份字段，升级时拒绝直接返回这些旧证据，并按原有后台预算重新关联和解析。即使替换文件保留相同大小与修改时间，也不能让旧 ID 指向它。Windows 目录枚举另行使用 Path.stat 获取有效文件身份；Linux 目录筛选使用区分大小写的路径范围。

## 数据库、凭据与维护

[数据库报告](validation/databases-product-v0.4.json) 包含真实隔离 MySQL 8.4.11 / PostgreSQL 17.11 的 63 项 adapter 测试，以及分页、断点、水位并列、更新、新增与完整巡检后删除。使用合成数据与只读检索账号，测试服务器已停止。表列选择、键/水位建议、别名与预检有闭环；建议不会自动授予表列权限。

Windows Credential Manager 已实际完成独立合成凭据的保存、跨进程读取、轮换及删除。Linux Secret Service 只有适配层测试，尚无真实桌面密钥环验收。数据库编辑窗口已通过真实隐藏 Tk 窗口的发现、选择、预检和保存回调测试，不能替代不同显示缩放下的人工体验验收。

[维护报告](validation/maintenance-v0.4.json) 覆盖持续暂停、资源退让、共享索引锁、迁移中断恢复、配置脱敏导出与恢复、受管备份清理、升级失败回滚和外置索引卸载。资源策略中的 CPU/电池/空闲场景使用可重复输入验证；没有把模拟电量当作笔记本实测。

## DSH 实际问答

[回答层报告](validation/dsh-answer-v04.json) 使用本机 DeepSeek Harness CLI 0.1.5-rc.1、已配置提供方与 gpt-6-sol，隔离 profile 和合成资料。实际会话调用 index_status → search → fetch → fetch → search → search，正确区分已批准 18,000 元与未批准草案 23,000 元；两个完整路径与第 2 行引用均核实；无答案表述限定为当前已索引范围。未修改用户默认 profile，未导出凭据值。

这是一组真实工具调用与回答闭环，不是普遍答案正确率或恶意文档防御的统计证明；最终原生包安装与工具接入另行验收。

## 实测速度、资源与检索质量

[5,000 个物理合成文件](validation/catalog-v0.4.json) 仅登记名称与元数据：首轮约 **1.652 秒**，无变化复查约 **1.232 秒**，采样峰值约 **31.8MiB**。测试立即推进调度轮次，排除后台等待；没有正文解析、语义模型和数百 GB 资料。与 v0.3 相比没有全面提速，文件身份检查增加了工作量。

[小语料资源测量](validation/resources-v0.4.json) 使用 16 文件、SQLite 8 行与固定本地 BGE 模型，采样范围为 daemon 及其 worker，包含回环 RPC：

| 指标 | 本次观察 |
|---|---:|
| 暖混合检索，20 次，中位数 / P95 | 24.844 / 39.701 ms |
| 索引及查询过程采样峰值 RSS | 328.672 MiB |
| 模型卸载后约 10 秒平均 RSS | 49.371 MiB |

测试把模型空闲卸载设为 2 秒，产品默认 120 秒；不含宿主 DSH、MCP 桥、系统文件缓存和其他应用。RSS 相加可能重复共享页，100ms 采样可能遗漏短峰值。32GB 主机使用低预算不能证明物理 8GB 设备承载能力。

[39 题检索集](validation/retrieval-v0.4.json)：18 个合成文件，23 个可回答语义题的 Recall@5、Recall@10 均为 **22/23**；关键词 6/6、文件名 3/3、精确数据库 3/3。唯一中文到英文跨语言题仍未进入前十，未把这一限制隐藏为全部通过。相似度只用于排序，不能作为回答可信度。
