# v0.5.2 暂停、连接诊断与文档目录默认范围验证

本轮修复包含常驻暂停控件、在途后台任务取消、具体连接错误码，以及首次安装默认文档目录。用户报告的故障位于另一台电脑/服务器，未取得该实例日志；以下证据不能证明远端故障的具体原因或所有连接失败都已消除。

## 代码与进程验证

- Windows 本地完整 Python 回归：556 通过、5 跳过。跳过项为 Linux 专属回退及未配置的真实 MySQL/PostgreSQL 服务验收，不能算作通过。
- 后台新增测试使用真实 CPU 子进程复现解析、数据库请求和语义编码在途任务。修复前暂停后仍在运行；修复后取消且待处理工作保留，不累积失败退避。语义测试替代了推理负载，未验证实际模型质量或大规模内存表现。
- 临时目录与真实 SQLite/daemon 验证：暂停期间新增文件/数据库行不进入索引、已有内容可查询、服务重启保留暂停、恢复后继续；数据库页中途暂停后的游标回放完整。
- Web bridge 使用真实 HTTP 测试服务注入拒绝连接、超时、断线、401、503、无效/超大响应等故障，核对错误码/建议且不泄露凭据。服务身份变更只重试一次只读状态；写操作不重放。
- Windows 文档目录通过 Known Folder API 只读核对，并与系统 Documents 路径一致，未扫描用户资料；XDG、本地化目录、不可用目录与旧配置保留有回归测试。

界面 fixture 和发行包验收记录在完成后写入本报告。本报告当前不以未完成检查作为成功证据。

8GB/16GB 实机、数百 GB 真实资料、远程 DSH 部署和多机传输未在本轮验证。没有新增聊天模型回答质量验收；没有声称暂停会取消独立模型下载或用户显式查询/刷新。
