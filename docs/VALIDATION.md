# v0.4 单机验证报告

本版把安装、检索、核实证据、解释漏检、资源控制、数据库配置和维护串成用户闭环。下列记录只说明已经执行的环境；物理 8GB/16GB、真实数百 GB 资料和长期运行验收仍待补齐。v0.3 的完整历史数据保留在 [历史验证报告](VALIDATION-v0.3.md)。

## 功能回归与产品路径

Windows 11（内核 10.0.22631）、Python 3.11.3、i7-13700、24 逻辑核、实际内存 31.814GiB。发行源码全量回归为 **449 passed、5 skipped，67.26 秒**；跳过一个非 Windows 分支、四个单独配置的数据库测试。详见 [测试记录](validation/tests-v0.4.json)，CI 与发行验收见下文。

组合筛选、文件名精确优先、上下文锚点、诊断与局部刷新、范围撤销、重复折叠、同路径替换和旧引用拒绝，由 [用户路径测试](../tests/test_product_journeys.py) 与 [官方 MCP 集成测试](../tests/test_mcp_integration.py) 验证。MCP 实际发现并调用 11 个工具。

v0.3 文件记录没有文件身份字段，升级时拒绝直接返回这些旧证据，并按原有后台预算重新关联和解析。即使替换文件保留相同大小与修改时间，也不能让旧 ID 指向它。Windows 目录枚举另行使用 Path.stat 获取有效文件身份；Linux 目录筛选使用区分大小写的路径范围。

真实 Linux CI 暴露出长期宿主未回收已退出后台子进程的问题，现已对本次启动的 daemon 和模型任务使用精确 Popen 回收；保留了原 PID 消失断言，并增加两条真实子进程测试。并发状态读取的缓存失效竞态由确定性交错测试复现为 TypeError，修复后通过。独立云端调度与浮点断言分别改为检查有界进度和合理数值误差，没有放宽结果 ID 或文件引用要求。

## 数据库、凭据与维护

[数据库报告](validation/databases-product-v0.4.json) 包含真实隔离 MySQL 8.4.11 / PostgreSQL 17.11 的 63 项 adapter 测试，以及分页、断点、水位并列、更新、新增与完整巡检后删除。使用合成数据与只读检索账号，测试服务器已停止。表列选择、键/水位建议、别名与预检有闭环；建议不会自动授予表列权限。

Windows Credential Manager 已实际完成独立合成凭据的保存、跨进程读取、轮换及删除。Linux Secret Service 只有适配层测试，尚无真实桌面密钥环验收。数据库编辑窗口已通过真实隐藏 Tk 窗口的发现、选择、预检和保存回调测试，不能替代不同显示缩放下的人工体验验收。

[维护报告](validation/maintenance-v0.4.json) 覆盖持续暂停、资源退让、共享索引锁、迁移中断恢复、配置脱敏导出与恢复、受管备份清理、升级失败回滚和外置索引卸载。资源策略中的 CPU/电池/空闲场景使用可重复输入验证；没有把模拟电量当作笔记本实测。

## DSH 实际问答

[回答层报告](validation/dsh-answer-v04.json) 使用本机 DeepSeek Harness CLI 0.1.5-rc.1、已配置提供方与 gpt-6-sol，隔离 profile 和合成资料。实际会话调用 index_status → search → fetch → fetch → search → search，正确区分已批准 18,000 元与未批准草案 23,000 元；两个完整路径与第 2 行引用均核实；无答案表述限定为当前已索引范围。未修改用户默认 profile，未导出凭据值。

这是一组真实工具调用与回答闭环，不是普遍答案正确率或恶意文档防御的统计证明；最终原生包安装与工具接入另行验收。

设置窗口的 [8 项新增交互测试](validation/product-ui-v0.4.json) 覆盖搜索、上下文、引用、独立路径诊断、快速切换结果、刷新后旧 ID 失效、维护互斥与恢复预览保护；在 900×700、740×560 下检查全部操作可滚动访问。相关路径合计 21 项通过。这里检查实际 Tk 几何和脚本操作，不宣称完成所有 DPI 下的人工视觉验收。

## 实测速度、资源与检索质量

[5,000 个物理合成文件](validation/catalog-v0.4.json) 仅登记名称与元数据：首轮约 **1.652 秒**，无变化复查约 **1.232 秒**，采样峰值约 **31.8MiB**。测试立即推进调度轮次，排除后台等待；没有正文解析、语义模型和数百 GB 资料。与 v0.3 相比没有全面提速，文件身份检查增加了工作量。

[小语料资源测量](validation/resources-v0.4.json) 使用 16 文件、SQLite 8 行与固定本地 BGE 模型，采样范围为 daemon 及其 worker，包含回环 RPC：

| 指标 | 本次观察 |
|---|---:|
| 暖混合检索，20 次，中位数 / P95 | 24.844 / 39.701 ms |
| 索引及查询过程采样峰值 RSS | 328.672 MiB |
| 模型卸载后约 10 秒平均 RSS | 49.371 MiB |

测试把模型空闲卸载设为 2 秒，产品默认 120 秒；不含宿主 DSH、MCP 桥、系统文件缓存和其他应用。RSS 相加可能重复共享页，100ms 采样可能遗漏短峰值。32GB 主机使用低预算不能证明物理 8GB 设备承载能力。

[39 题检索集](validation/retrieval-v0.4.json)：18 个合成文件，23 个可回答语义题的 Recall@5、Recall@10 均为 **22/23**；关键词 6/6、文件名 3/3、精确数据库 3/3。唯一中文到英文跨语言题仍未进入前十，未把这一限制隐藏为全部通过。相似度只用于排序，不能作为回答可信度。

另行执行 [有限并发与生命周期复验](validation/product-rpc-v0.4.json)，24 个初始合成文件、约 7.6KB，后台 45 秒完成 107 次改写，各模式采集 121 次并发查询：

| 回环 RPC 指标 / ms | 文件名 | 关键词 | 语义 |
|---|---:|---:|---:|
| daemon 重启后首次查询 | 22.460 | 15.790 | 496.002 |
| 暖查询 P95 | 24.435 | 31.831 | 31.645 |
| 建库并发查询 P95 | 26.052 | 28.247 | 50.117 |

“首次”指服务重启，不是清空操作系统磁盘缓存。暂停期间搜索、定时到期、暂停状态跨重启、恢复积压通过；新增文件关键词恢复 3.485 秒，向量追平 4.407 秒，最终 25/25 片段完成且服务停止。复现入口是 scripts/measure_product_v04.py，测试过程不下载模型、不访问业务资料。

报告保留此前一次已被脱敏的状态查询错误，以及诊断脚本连续重启时一次 15 秒停止超时记录。状态缓存竞态已确定性修复，但原始脱敏异常没有堆栈，不能证明同一根因；后续 Windows CI 复现了相同停止超时表现，并通过真实读句柄对照证明状态文件单次删除的缺陷；现已增加所有权复核及 5 秒有界重试。另为原生升级目录切换增加短暂锁定重试，永久失败仍回滚。无法追溯诊断脚本原事件是否同因；最终普通流程无重试掩盖并通过，不把它写成长期稳定性验收。

## 发布与平台验收

[最终 CI](validation/ci-v0.4.json) 两个平台通过：Windows 为 448 passed / 6 skipped，Node 15/15；Ubuntu 24.04 为 433 passed / 21 skipped，Node 12 passed / 3 skipped。Windows 少一项是 CI 环境没有该测试要求的控制台安装入口，GUI 测试没有跳过；本机真实安装验收覆盖控制台入口。

[Ubuntu 无界面安装](validation/linux-v0.4.json) 实际完成中文/空格路径、无模型基础能力、重复安装保留配置、诊断、暂停刷新、配置导出、索引迁移、保留卸载重装与只删除受管数据。使用手动启动模式；未测试 systemd 用户会话、Linux 桌面密钥环或 Linux 本地模型。

[最终 Windows 安装包报告](validation/install-v0.4.json) 对应 candidate-3、发行源代码和 wheel/native 执行文件 SHA-256。从 ZIP 全新解压验证原生与 bootstrap，覆盖基础先可用、重复安装、离线模型与语义、11 个 MCP 工具、外置索引迁移后重装、保留数据卸载重装、只删除受管数据。实际 v0.3→v0.4 升级及真实新 daemon 启动失败回滚通过。真实 DSH 首次激活安装后台、发现工具和检索通过；退出宿主仍保留共享后台，二次激活保持配置。测试只使用隔离合成资料，已停止并清理所属实例。

发行资源为 Windows x64 原生 ZIP、CPython 3.11 x64 bootstrap ZIP、两个清单、项目 wheel 与 SHA256SUMS.txt。最终打包复核源码、提交内容、wheel 与清单的字节哈希，文档刷新不替换运行时；包内逐文件校验和与外部资源校验一并提供。源码支持不等于所有发行环境已经验证。
