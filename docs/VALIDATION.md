# 单机验证报告 · 0.2.0

日期：2026-09-25。结论：默认本机范围、可选目录、六项优化及 Windows 原生/Bootstrap 安装已实现并验证。新安装会发现当前账号可访问的本地磁盘；本轮只探测磁盘根目录，没有把用户整台电脑的真实文件纳入索引。真实几百 GB 正文、物理 8GB/16GB 机器和多机仍未验收。

旧版数据保留在 [0.1.0 历史报告](VALIDATION-v0.1.md)。本报告按功能、质量、资源、查询内核和安装分别给出证据，不把它们混为同一种性能指标。

## 环境和回归

Windows 11（内核 10.0.22631），Python 3.11.3，i7-13700，16 个物理核 / 24 个逻辑核，约 31.8GiB 物理内存。没有单独核实磁盘介质型号。

最终完整回归：**208 passed，2 skipped，0 warnings，35.78 秒**，见 [tests-v0.2.json](validation/tests-v0.2.json)。两个 skipped 是需专用连接配置的外部数据库测试；真实 MySQL 8.4.11、PostgreSQL 17.11 已另行执行隔离测试，包括 61 项 adapter 测试及数据库同步生命周期，见 [databases-v0.2.json](validation/databases-v0.2.json)。没有访问业务数据库。

## 后台服务资源和完整 RPC 查询

使用新建的同类合成资料，核对 16 个文件、8 条数据库记录和 87 个已嵌入片段。外部采样器每 100ms 统计 daemon 及其后代进程。详见 [resources-v0.2.json](validation/resources-v0.2.json)。

| 阶段 | 实测 RSS |
|---|---:|
| 首次索引进程树峰值 | 299.102MiB |
| 模型热查询峰值 | 189.359MiB |
| 模型卸载后静置约十秒 | 42.129MiB |
| 数据及外部模型磁盘占用 | 约 26.3MiB |

20 次本地 RPC 语义查询，中位数 36.375ms，P95 56.997ms，最大 69.344ms；只对应这 87 个片段。测试把模型闲置释放设为两秒，产品默认 120 秒。索引观测时长约 7.787 秒，24 逻辑核整机 CPU 平均约 1.262%。

测试期间另有 10 万段基准等任务运行，结果不作为隔离环境速度对比。RSS 求和可能重复计算共享页，采样可能遗漏短峰值；不含 DSH、MCP 桥、系统缓存和其他应用。Windows Job 内存限额是**单 worker 提交虚拟内存**，不是整个应用的 RSS 硬上限；Linux 目前没有同等硬限额。测试服务及已采样 worker 已退出。

## 10 万段合成索引

10 万文档记录、10 万片段，正文 **27,026,395 字节**。没有创建 10 万个真实源文件；向量为固定随机种子的 512 维合成数据，不代表语义质量。每类 100 次暖查询，旧版为 200 次。详见 [benchmark-v0.2.json](validation/benchmark-v0.2.json)。

| 项目 | 0.1.0 | 0.2.0 |
|---|---:|---:|
| 完成增删后的索引占用 | 722.78MiB | 506.51MiB |
| 文件名 SQL 查询内核 P95 | 2.110ms | 2.210ms |
| FTS5 关键词候选内核 P95 | 90.763ms | 105.115ms |
| 合成向量 ANN 查询内核 P95 | 3.757ms | 10.021ms |
| 首次 ANN 构建 | 646.102 秒 | 739.306 秒 |
| 1,000 新增 + 1,000 删除的 ANN 同步 | 7.842 秒 | 13.435 秒 |

本轮最终磁盘占用减少 **29.92%**。第一次构建后的占用是 392.41MiB；增量发布后最终占用包含当前及上一版两个约 111.83MiB 的 ANN 快照，这是保持查询可用的空间成本。新正文和合成向量入库 33.598 秒，增量源更新 0.464 秒，增量未全量重建。进程树采样峰值 235.88MiB。

**没有测出速度提升，不宣称新版比旧版更快。** 新版有独立进程、资源调度、快照保留等成本，期间还有其他主机负载；两轮不构成严格隔离的速度对照。优化的实证收益是较小的索引、建库与查询分离，以及覆盖/恢复能力。

查询内核不包含完整 Engine 适应性候选扩展、真实文件权限/过期检查、模型编码、MCP、原文取回和聊天回答。27MB 合成短文本不等于几百 GB 真实资料。首次真实索引还包含枚举、解析、嵌入与节流，不能用这里的毫秒数字承诺整机查询时间。

## 发行包与安装

提供 Windows amd64 原生 ZIP、CPython 3.11 x64 bootstrap ZIP、项目 wheel、发行清单和 SHA-256 校验。原生包包含运行时，不调用系统 Python；默认包不含模型。模型在首次安装下载或使用指定离线目录。

从两个 ZIP 重新解压后，在 Windows PowerShell 5.1 下验证：中文/空格程序、数据、资料、模型路径；安装并启动、实际语义查询、SQLite 查询、五个 MCP 工具、重复安装保留范围、卸载清理测试程序及数据。源码哈希、每文件校验和 ZIP 完整性通过。实际记录见 [install-v0.2.json](validation/install-v0.2.json)。

本轮隔离安装测试使用 `NoAutostart`，未执行全机扫描或注册试验登录项；0.1.0 曾执行用户启动项的隐藏触发测试，不能代替本版实际注销/重启验收。原生包没有代码签名，Windows 版本与组织策略差异仍需实机确认。GUI 已验证构造、范围保存与服务重启顺序，完整人工显示缩放验收仍待进行。

```powershell
python -m pytest -q
python scripts/create_demo.py --output .demo-new
python scripts/evaluate_search.py --demo .demo-new --model <已有模型目录> --data .runtime/quality-new --output quality.json

```
