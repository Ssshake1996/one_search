# v0.4 单机产品实施与验收

用户已确认：README 是 Agent 安装的权威入口；先完成单机 P0/P1 用户路径，保留多机接口。新安装默认当前账户可访问的整机本地磁盘，旧配置保持原范围。后台优先节约资源，正文允许延迟几分钟。无图形安装向导，复用 CLI、MCP 与现有设置窗口。

## 完成定义

Agent 仅依据 README 就能安装、启动、连接指定 DSH profile 并验证基础检索。模型下载和首轮索引不阻塞基础能力。用户能筛选资料、核实来源、解释漏检和过期、控制资源、恢复常见失败、更新迁移及卸载。任何尚未执行的真实硬件、规模、平台和 DSH 回答层验收保持待验收，不以合成测试替代。

## 技术边界

- MCP、CLI 和设置窗口共享后台接口；检索只读，刷新、暂停、维护为显式操作。来源文字不作为指令。
- 支持正文格式：TXT/MD/LOG/代码与配置、JSON/JSONL/XML/HTML、CSV/TSV、DOCX/XLSX/PPTX、文本 PDF。具体限制继续以 FORMATS.md 为准。
- 数据库：SQLite、MySQL、PostgreSQL，只读账户和表列白名单。准确编号、金额、计数走结构化实时查询。
- 模型本机运行；相似度不是答案置信度。没有完整覆盖不声称资料不存在。
- OCR、旧 Office、压缩包正文、网络来源按真实漏检价值另行评估；本轮不承诺实现。多机只保留节点/来源/健康/权限接口。

## 测量目标（不是已获得的结果）

固定硬件、语料、配置和版本，分别报告冷查询、暖查询与建库并发的端到端本地服务延迟。目标暖 P95：文件名 ≤300ms、关键词 ≤1s、语义 ≤2s；DSH 生成时间单列。无积压、支持的小文件更新目标 ≤5 分钟。记录文件数、支持正文量、片段与向量数，不用磁盘标称容量推算速度。
